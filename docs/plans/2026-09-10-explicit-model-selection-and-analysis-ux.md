# 显式模型选择与论文分析交互改进计划

## 1. 目标与范围

- 让“自选论文”覆盖整个文献库，支持综合检索、分页和跨页保留选择。
- 所有用户主动发起的大模型任务显式选择模型，不再通过“场景默认模型”隐式决定。
- 将采集服务密钥从模型配置中拆分到独立的采集设置页面。
- 修复统一文献中 `year` / `unassigned` / `unknown` 内部标记泄漏造成的错误卷期展示。
- 为“翻译本期”增加模型选择，并把语言显示控件改成“原文 / 中文译文”分段控件。
- 将视频笔记和遗留期号分析接口一并改为显式模型输入，避免留下隐藏模型入口。

## 2. 已确认决策与约束

- “自选论文”不是推荐列表，必须能访问和检索全部文献。
- 用户可见的大模型操作必须展示并提交具体模型档案；未选择模型时不得启动任务。
- `paper_analysis`、`paper_translation`、`video_note` 等场景名继续作为 Prompt 与调用类型标识，但不再承担模型绑定。
- 删除前端“场景默认模型”配置及后端场景绑定 API/数据表；现有模型档案继续保留。
- 采集密钥进入 Collection 下的独立“采集设置”页面，模型设置页只管理模型档案和模型密钥。
- Scopus 无期号论文在原始采集层使用 `unassigned` 分组，在统一文献层保存空期号；`unknown` 卷号同理不进入统一文献字段。
- 外文期号详情使用“原文 / 中文译文”二段式切换；没有译文时中文选项不可用。
- 不覆盖工作区已有改动；正式数据库通过 Alembic 迁移修复并核对数据。

## 3. 实施步骤

1. 增加后端回归测试：综合文献检索、内部卷期标记归一化、翻译/分析/视频任务显式模型校验与模型快照。
2. 扩展文献列表 API 的综合关键词查询，前端自选论文增加防抖搜索、分页、总数和跨页选择。
3. 移除场景绑定 API 与模型解析回退，所有 LLM 调用链显式传递 `profile_id`。
4. 为期号翻译和视频笔记任务增加模型字段、请求校验、执行传递和结果快照。
5. 增加数据库迁移：修复统一文献卷期内部标记、增加任务模型字段并删除场景绑定表。
6. 拆分采集设置页面，更新导航、路由和模型设置页面。
7. 将语言下拉框改为分段控件，并补充未翻译、翻译中、已翻译状态。
8. 更新当前架构、目标规范和决策文档，记录实际实现。
9. 运行后端测试、前端单元测试、类型检查、Lint、构建、分包检查和 Playwright 浏览器验证。
