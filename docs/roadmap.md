# Roadmap

## 项目北极星

把 Knowledge Vault 打造成一个服务个人研究与知识工作的长期系统，而不是只做一个“文献管理器”。

## 当前阶段

当前项目处在“从文献管理扩展到知识工作台”的早期阶段，已有基础包括：

- 文献管理
- 期刊采集
- 原始数据入库
- 翻译与分析
- 派生产物导出
- 视频转笔记

## 近期重点

### 1. 稳定采集链路

- 提高国内/国外期刊采集的稳定性
- 明确原始数据、翻译、分析之间的状态流转
- 降低依赖脚本式人工处理的环节

### 2. 完善知识整理能力

- 把采集结果更自然地接入文献条目、标签、文件夹和笔记
- 为后续知识沉淀打基础

### 3. 拓展多源内容输入

- 让视频内容进入统一工作台
- 稳定“链接 -> 字幕 -> 笔记”的自动化流程
- 为后续更多媒体来源打基础

### 4. 统一项目信息结构

- 持续维护 README、开发文档、路线图和项目日志
- 让 Agent 在新会话里可以快速恢复上下文

## 中期方向

- 支持更多知识来源的采集与导入
- 引入更完整的知识整理与关联能力
- 增强摘要、分析、比较、再利用等 AI 工作流
- 逐步形成“采集 -> 整理 -> 沉淀 -> 输出”的闭环

## 暂不追求

- 为了堆功能而增加彼此割裂的新子项目
- 在没有文档和结构约束的情况下快速扩张
- 只围绕“文献”单一对象设计整个系统
